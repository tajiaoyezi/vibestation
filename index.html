01 · 特性

日常开发里被忽视的
细节，重新做一遍。

不发明新概念，专注把多 Tab 终端、Git 视图和工作区切换这几件事做到接近 IDE 的完成度。

多 Tab 终端

每个 Tab 独立 shell · 支持 Claude Code、Codex CLI、zsh、cargo 等长任务并行运行。

pty · session · split pane

Git 工作台

log / status / diff 三视图联动 · 文件级 stage、commit、行内 diff 直接在视图里完成。

log · diff · staging

跨项目管理

多 workspace 一窗口直达 · 每个项目保留独立 tab 布局与终端会话，切换零等待。

workspace · context

崩溃恢复

会话状态周期持久化 · 意外关闭后重启自动恢复终端历史、布局与未保存的提交草稿。

persistence · session

03 · 安装

两条命令，
装到本机。

当前为 unsigned alpha 构建。下载后需要解除 quarantine attribute，五分钟内可用。

所有 Release ↗
1

下载 .dmg

从 Release 页拉取最新的 macOS aarch64 (Apple Silicon) 构建，约 12 MB。

$ curl -L https://github.com/tajiaoyezi/vibestation/releases/\
   latest/download/Vibestation_aarch64.dmg -o Vibestation.dmg
2

挂载并拖到 Applications

双击 dmg，把 Vibestation.app 拖到 Applications 目录。

3

解除 quarantine（unsigned 构建必要步骤）

v0.1 alpha 暂未做苹果开发者签名，需要手动移除隔离属性，否则会被 Gatekeeper 拦截。

$ xattr -cr /Applications/Vibestation.app
$ open /Applications/Vibestation.app
1

下载 .deb 包

x86_64 / aarch64 双架构提供。从 Release 页拿到对应版本。

$ curl -L https://github.com/tajiaoyezi/vibestation/releases/\
   latest/download/vibestation_amd64.deb -o vibestation.deb
2

用 apt 安装

apt 会自动拉取 webkit2gtk 等 Tauri 运行时依赖。

$ sudo apt install ./vibestation.deb
3

启动

从 application launcher 启动，或直接在终端调用。

$ vibestation

为 CLI agent 用户打造的多 Tab 终端与 Git 工作台。
